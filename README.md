# CMS 관악 수학학원 · QR 수학퀴즈 이벤트 운영 및 배포 가이드

이 문서는 `index.html`을 실제 이벤트에 사용하기 위한 **구글 폼/시트 연동 설정**, **entry 번호 적용 방법**, **Netlify Drop / GitHub Pages 배포 방법**, **사전 테스트 체크리스트**, **중복 참여 확인 수식**을 정리한 운영 매뉴얼입니다.

---

## 1. 구글 폼 설정 체크리스트 (필수)

구글 폼이 로그인을 요구하거나 미게시 상태이면, 학부모/학생이 휴대폰으로 제출했을 때 **구글 시트에 데이터가 쌓이지 않습니다.** 아래 항목을 반드시 확인하세요.

- [ ] **질문 6개 생성 (단답형 텍스트 권장)**
  - 구글 폼에서 선택형(객관식/드롭다운)으로 만들면 철자나 공백이 조금만 달라도 값이 누락될 수 있으므로, **6개 질문 모두 `단답형(Short answer)`으로 설정**하는 것이 가장 안전합니다.
  - 질문 순서:
    1. `이름` (학생 이름)
    2. `학교` (학교명)
    3. `학년` (초5 / 초6 / 중1 / 중2 / 중3)
    4. `전화번호` (학부모 전화번호)
    5. `광고동의` (동의 / 미동의)
    6. `점수` (예: 3/3)
- [ ] **이메일 수집 끄기**
  - 구글 폼 상단 **[설정]** 탭 → **[응답]** 클릭
  - `이메일 주소 수집` → **`수집하지 않음`** 선택
- [ ] **로그인 필요 기능 모두 끄기**
  - **[설정]** 탭 → **[응답]** 항목에서:
    - `응답 횟수 1회로 제한` → **끄기 (비활성화)** *(켜져 있으면 구글 로그인을 강제합니다)*
    - (학원/기업 Google Workspace 계정인 경우) `[조직] 및 신뢰할 수 있는 조직의 사용자로 제한` → **끄기 (비활성화)**
- [ ] **폼 게시 및 응답 허용 확인**
  - 상단 **[응답]** 탭에서 `응답 받기` 스위치 **켜기**
  - 우측 상단에 **[게시]**(또는 **[게시됨]** 옵션) 버튼이 있다면 클릭하여 `응답자 뷰` 권한이 **`링크가 있는 모든 사용자`**로 되어 있는지 확인
- [ ] **응답 → 구글 시트 연결**
  - 상단 **[응답]** 탭 → 우측 상단 초록색 **[Sheets에 연결]**(또는 **[스프레드시트에서 보기]**) 클릭
  - `새 스프레드시트 만들기` 선택 후 **[만들기]** 클릭

## 2. `entry.XXXX` 번호 적용 현황 및 변경 방법

현재 `index.html` 상단 `CONFIG`에는 공개된 구글 폼 ID와 6개 질문의 실제 `entry.XXXX` 번호가 **모두 매핑 완료**되어 있어 바로 배포·운영 가능합니다.

| 항목 | 질문명 | 현재 매핑된 번호 |
| :--- | :--- | :--- |
| 공개 폼 ID (`formId`) | CMS관악 QR 이벤트 참여 신청서 | `1FAIpQLSc2733OGFeWIFfxc2-SzpBp1WfmX4QHVwRVFcB4PJltqI1lkA` |
| `student` | 1. 이름 | `entry.1963285764` |
| `school` | 2. 학교 | `entry.1515178573` |
| `grade` | 3. 학년 | `entry.1171836381` |
| `phone` | 4. 전화번호 | `entry.1217460375` |
| `marketing` | 5. 광고동의 | `entry.940447753` |
| `score` | 6. 점수 | `entry.1726598503` |

*(추후 새로운 구글 폼을 만들어 교체해야 할 때만 아래 절차에 따라 변경하세요.)*

### Step 1. 새 구글 폼에서 '미리 채워진 링크' 발급받기
1. 구글 폼 편집 화면 우측 상단 **점 3개(`⋮`) 아이콘** 클릭 → **[미리 채워진 링크 가져오기]** (또는 **[Get pre-filled link]**) 클릭
2. 새 탭에 폼이 열리면 6개 항목에 순서대로 구분하기 쉬운 값을 입력:
   - 이름: `홍길동` / 학교: `관악초` / 학년: `초5` / 전화번호: `010-1234-5678` / 광고동의: `동의` / 점수: `3/3`
3. 하단의 **[링크 생성(Get link)]** 버튼 클릭 → 화면 왼쪽 아래 알림창의 **[링크 복사(Copy link)]** 클릭
4. 복사된 URL 예시:
   ```text
   https://docs.google.com/forms/d/e/1FAIpQLSc2733OGFeWIFfxc2-SzpBp1WfmX4QHVwRVFcB4PJltqI1lkA/viewform?usp=pp_url&entry.1963285764=홍길동&entry.1515178573=관악초&entry.1171836381=초5&entry.1217460375=010-1234-5678&entry.940447753=동의&entry.1726598503=3/3
   ```

### Step 2. `index.html`의 `CONFIG` 수정하기

`index.html` 파일을 메모장이나 코드 에디터(VS Code 등)로 열고, `<script>` 바로 아래의 `CONFIG` 객체를 수정합니다.

#### 방법 A (가장 쉬움): 복사한 미리 채워진 링크 통째로 붙여넣기
`prefilledLink` 큰따옴표(`""`) 사이에 복사한 링크 전체를 붙여넣으면, 코드가 자동으로 폼 ID와 6개 `entry.XXXX` 번호를 순서대로 추출해 전송합니다.
```javascript
const CONFIG = {
  prefilledLink: "https://docs.google.com/forms/d/e/1FAIpQLSd.../viewform?usp=pp_url&entry.111=홍길동&entry.222=관악초...",
  // ...
};
```

#### 방법 B: `formId`와 `entries` 번호를 직접 입력하기
복사한 URL에서 각 항목 앞의 `entry.숫자`를 확인하여 직접 입력할 수도 있습니다.
- 만약 복사한 링크가 `/forms/d/e/1FAIpQLS.../viewform` 형태라면 `formId`에 `1FAIpQLS...`를 넣고 `isPublicPublishedId: true`로 설정하세요.
```javascript
const CONFIG = {
  prefilledLink: "",
  formId: "1FAIpQLSdxxxxxxx...", // 또는 "1rtW7uyVpvHRsfOakASRclvCtyEnzAi7D958F-sn0h1g"
  isPublicPublishedId: true,     // 1FAIpQL... 형태면 true, 일반 ID면 false
  entries: {
    student:   "entry.111111111", // 1. 학생 이름
    school:    "entry.222222222", // 2. 학교명
    grade:     "entry.333333333", // 3. 학년
    phone:     "entry.444444444", // 4. 학부모 전화번호
    marketing: "entry.555555555", // 5. 광고성 정보 수신 동의
    score:     "entry.666666666"  // 6. 점수
  }
};
```

## 3. 배포 방법 (Netlify Drop / GitHub Pages)

### 방법 1. Netlify Drop으로 1분 만에 배포하기 (추천)
1. 폴더 안에 `index.html` 파일이 들어 있는지 확인합니다. *(파일명이 반드시 `index.html`이어야 합니다)*
2. 브라우저에서 [https://app.netlify.com/drop](https://app.netlify.com/drop) 접속 (무료 회원가입/로그인)
3. 프로젝트 폴더(`cms-gwanak-qr-math-quiz` 폴더 전체)를 점선 영역(**"Drag and drop your site output folder here"**)에 마우스로 끌어다 놓습니다.
4. 몇 초 후 배포가 완료되며 `https://xxxx.netlify.app` 형태의 접속 주소가 생성됩니다.
5. **[Site configuration]** → **[Change site name]**에서 원하는 주소(예: `https://cms-gwanak-quiz.netlify.app`)로 변경할 수 있습니다.
6. 생성된 URL로 전단지용 QR 코드를 제작합니다.

### 방법 2. GitHub Pages로 배포하기
1. [GitHub](https://github.com)에 로그인 후 우측 상단 **`+`** → **[New repository]** 클릭
2. Repository 이름을 입력(예: `cms-gwanak-quiz`)하고 **Public** 선택 후 **[Create repository]** 클릭
3. **[uploading an existing file]** 링크를 클릭하여 `index.html` (및 `README.md`) 파일을 드래그 앤 드롭하고 하단 **[Commit changes]** 클릭
4. 저장소 상단 **[Settings]** 탭 → 좌측 메뉴 **[Pages]** 클릭
5. **Build and deployment** → **Branch**를 `None`에서 `main`(또는 `master`), 폴더를 `/ (root)`로 변경 후 **[Save]** 클릭
6. 1~2분 뒤 페이지 상단에 표시되는 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속을 확인합니다.

## 4. 오픈 전 테스트 체크리스트

인쇄물(전단지) QR 코드 배포 전에 아래 항목을 반드시 점검하세요.

- [ ] **시크릿 모드(비로그인) 폼 접근 확인**: 크롬 시크릿 창에서 구글 폼 응답 링크를 열었을 때 로그인 화면 없이 폼이 열리는지 확인
- [ ] **정답/오답 플로우 확인**:
  - 3문제 모두 맞혔을 때만 개인정보 입력 화면(`STEP 03`)이 나오고, 선택한 학년이 자동 선택되어 있는지 확인
  - 1문제라도 틀렸을 때 개인정보 입력 화면 없이 `"다시 도전해보세요!"` 안내 화면이 나오는지 확인
- [ ] **전화번호 검증 확인**:
  - 숫자만 `01012345678` 입력 시 `010-1234-5678`로 하이픈이 자동 입력되는지 확인
  - `011-...` 또는 자릿수가 부족한 번호 입력 시 안내 메시지와 함께 제출이 차단되는지 확인
- [ ] **환경별 실제 제출 → 구글 시트 반영 확인**:
  - [ ] **아이폰 (iOS Safari)**: 입력창 터치 시 화면이 강제로 확대(Zoom)되지 않고 제출 후 구글 시트에 행이 추가되는지 확인
  - [ ] **안드로이드 (Android Chrome)**: 화면 가로 스크롤 없이 버튼 터치 및 제출 후 구글 시트에 반영되는지 확인
  - [ ] **카카오톡 / 네이버 앱 인앱 브라우저**: 카톡 채팅방에 링크를 공유했을 때 제목/설명(`og:title`, `og:description`) 미리보기가 잘 뜨는지, 링크를 눌러 인앱 브라우저에서 제출했을 때 구글 시트에 정상 저장되는지 확인
- [ ] **테스트 데이터 정리**: 오픈 직전 구글 시트에 쌓인 테스트용 행들을 삭제

## 5. 구글 시트에서 전화번호 중복 참여 표시하기

구글 시트의 기본 열 구성이 아래와 같다고 가정합니다 (`A열`: 타임스탬프, `B열`: 이름, `C열`: 학교, `D열`: 학년, `E열`: 전화번호, `F열`: 광고동의, `G열`: 점수).

### 방법 A. 조건부 서식으로 중복 전화번호 행에 색상 칠하기 (추천)
1. 구글 시트에서 전화번호가 들어 있는 **`E2:E1000`** 범위를 마우스로 선택합니다. (또는 전체 행을 색칠하려면 `A2:G1000` 선택)
2. 상단 메뉴 **[서식]** → **[조건부 서식]** 클릭
3. 우측 패널의 **서식 규칙**에서 `셀이 비어 있지 않음`을 클릭하여 맨 아래 **[맞춤 수식]**으로 변경
4. **값 또는 수식** 입력창에 아래 수식을 붙여넣습니다:
   - `E2:E1000`만 색칠할 때:
     ```excel
     =COUNTIF($E$2:$E$1000, E2) > 1
     ```
   - `A2:G1000` 전체 행을 색칠할 때:
     ```excel
     =COUNTIF($E$2:$E$1000, $E2) > 1
     ```
5. **서식 스타일**에서 배경색을 연한 빨간색/노란색으로 지정하고 **[완료]**를 클릭하면, 동일 전화번호로 2번 이상 참여한 행이 자동으로 강조 표시됩니다.

### 방법 B. 옆 열(`H열`)에 '중복 여부' 텍스트로 표시하기
1. `H1` 셀에 제목으로 **`중복확인`** 입력
2. `H2` 셀에 아래 수식 중 하나를 입력:
   - **단순 중복 표시 (2회 이상 참여한 번호 모두 '중복' 표시)**:
     ```excel
     =IF(E2="", "", IF(COUNTIF($E$2:$E$1000, E2)>1, "⚠️ 중복(" & COUNTIF($E$2:$E$1000, E2) & "회)", "최초"))
     ```
   - **최초 1회는 '정상 지급 대상', 이후 참여분부터 '중복 참여'로 구분 표시 (실무 추천)**:
     ```excel
     =IF(E2="", "", IF(COUNTIF($E$2:E2, E2)>1, "⚠️ 중복참여(" & COUNTIF($E$2:E2, E2) & "회차)", "✅ 최초참여"))
     ```
3. `H2` 셀 우측 하단 모서리 점을 잡고 아래로 드래그하여 수식을 복사합니다.
